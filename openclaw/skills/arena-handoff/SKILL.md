# Arena handoff

Arena — это отдельный агент с сильной моделью, который открывается в браузере на одну сессию и
имеет полный доступ к одному git-репозиторию. Он не живёт 24/7 и не может быть вызван по API,
поэтому «позвать Arena» = положить файл задачи в репозиторий и попросить человека открыть сессию.

Используй этот скилл, когда задача:

- затрагивает **3+ файла** или требует рефакторинга/переписывания модуля;
- требует прогона тестов, сборки, чтения большого объёма кода;
- «дорогая» по рассуждению (архитектура, отладка невоспроизводимой ошибки);
- должна закончиться **коммитом или PR**, а не сообщением в чат.

Не используй для: ответа на вопрос, напоминания, одной команды в shell, отправки сообщения.

## Как оформить задачу

1. Убедись, что рабочая копия репозитория обновлена: `git pull --ff-only`.
2. Создай файл `tasks/inbox/TASK-<NNN>.md` по шаблону из `tasks/README.md`.
3. Обязательно заполни `goal`, `done_when`, `paths` и `constraints`. Если пользователь не назвал
   критерий готовности — **спроси его одной строкой**, не выдумывай.
4. Закоммить и запушь:
   ```bash
   git add tasks/inbox/TASK-<NNN>.md
   git commit -m "task(TASK-<NNN>): <короткое название>"
   git push
   ```
5. Ответь пользователю ровно одной строкой:
   `Задача TASK-<NNN> в очереди. Открой сессию Arena и напиши: «сделай всё из tasks/inbox».`

## Как принимать результат

- `tasks/done/TASK-<NNN>.md` существует → задача закрыта. Прочитай раздел `## Result` и передай
  пользователю 2–4 пункта: что изменено, что осталось, что требует его решения.
- `status: blocked` → перескажи блокер и задай уточняющий вопрос, задачу не переписывай.
- Не редактируй файлы в `tasks/done/` и не «переоткрывай» задачу самовольно: новая задача — новый номер.

## Правила гигиены

- Один файл = одна задача. Не сваливай пять правок в один TASK.
- Никогда не клади в задачу секреты, токены, пароли или содержимое личной переписки.
- Не создавай больше 3 задач за один раз — человек всё равно откроет одну сессию.
- Если задача отменена — не удаляй файл, а допиши `status: cancelled` и причину.
