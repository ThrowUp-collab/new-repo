# aar_archiver — офлайн-копия AAR-треда с форума Paradox

Один Python-скрипт, который скачивает тред XenForo (форум Paradox Plaza и любой
другой на этом движке) и превращает его в аккуратную локальную копию:
читаемый HTML-файл, Markdown, JSON и опционально EPUB. Все скриншоты
загружаются локально, ленивая подгрузка картинок форума распаковывается,
подписи пользователей и кнопки интерфейса вырезаются.

**Зависимости: никаких.** Только стандартная библиотека Python 3.8+.

---

## Быстрый старт

```bash
python3 aar_archiver.py \
  https://forum.paradoxplaza.com/forum/threads/siberian-prosperity-an-economic-ck2-aar.1567294/ \
  --out "Siberian Prosperity" --epub
```

Скрипт сам определит заголовок треда, его автора и количество страниц,
пройдёт по всем страницам, скачает картинки и сложит всё в папку
`Siberian Prosperity/`.

Открыть копию: просто двойной клик по `siberian-prosperity-an-economic-ck2-aar.html`.

### Windows: запуск двойным кликом

`run_archiver.bat` — двойной клик открывает консоль, скрипт сам спросит ссылку
на тред и дополнительные флаги, а в конце окно **не закроется**, пока вы не
нажмёте Enter. Это же работает при любой ошибке: сообщение останется на экране.

В консоли батник принимает аргументы как обычно:

```bat
run_archiver.bat https://forum.paradoxplaza.com/forum/threads/<slug>.<id>/ --op-only --epub
```

Если запускать `aar_archiver.py` напрямую без аргументов, скрипт не ругается
загадочным `the following arguments are required`, а печатает справку с примером.
Весь вывод дополнительно пишется в `archiver.log` внутри папки результата
(отключается флагом `--no-log`) — так сообщение не потеряется, даже если
окно закрылось.

### Посмотреть результат, не запуская скрипт

В `tests/sample_output/` лежит готовый пример того, что получается на выходе
(собран из синтетических фикстур, не из настоящего AAR):

- `single-file.html` — копия одним файлом, картинки вшиты, открывается где угодно;
- `sample-realm-diary.html` — обычный вариант с папкой `images/`;
- `markdown/all.md`, `posts.json`, `raw/` — остальные форматы.

## Что получается

```
Siberian Prosperity/
├── siberian-prosperity-an-economic-ck2-aar.html   читалка: оглавление + все посты
├── siberian-prosperity-an-economic-ck2-aar.epub   книжка для ридера (--epub)
├── posts.json                                     структура: автор, дата, id, HTML, Markdown
├── markdown/
│   ├── all.md                                     весь тред одним файлом
│   └── page-001.md …                              по странице за раз
├── images/                                        все скриншоты, локально
└── raw/page-001.html …                            исходный HTML страниц (страховка)
```

Папка `raw/` — это необработанные страницы. Если парсер когда-нибудь
споткнётся о новую вёрстку форума, текст всё равно останется у вас,
и его можно будет разобрать заново, не качая тред повторно.

## Полезные флаги

| Флаг | Что делает |
| --- | --- |
| `--op-only` | оставить только посты автора треда — чистый текст AAR без чужих ответов |
| `--author NICK` | то же, но по конкретному нику |
| `--pages 1-5` / `--pages 1,3,7-9` | скачать не всё, а выбранные страницы |
| `--max-pages N` | остановиться на N-й странице |
| `--epub` | собрать ещё и EPUB |
| `--inline-images` | вшить картинки в HTML как `data:` — копия одним файлом, можно пересылать |
| `--no-images` | не качать картинки (быстро, только текст) |
| `--formats html,md,json` | какие форматы писать |
| `--resume` | не перекачивать страницы, которые уже лежат в `raw/` |
| `--source wayback` | брать снимки из web.archive.org, а не с форума |
| `--delay 3` | пауза между запросами, сек (по умолчанию 3 — не нагружайте форум) |
| `--cookies 'xf_user=…'` / `--cookie-file cookies.txt` | если страница доступна только залогиненным |
| `--out DIR` | куда складывать (по умолчанию `out/`) |
| `--quiet` | меньше сообщений |

### Примеры

```bash
# только авторский текст, без ответов в треде
python3 aar_archiver.py <url> --op-only --out "AAR (clean)"

# один самодостаточный файл, который не потеряет картинки
python3 aar_archiver.py <url> --inline-images --formats html --out single

# доначать прерванное скачивание
python3 aar_archiver.py <url> --resume

# первые 5 страниц и EPUB для телефона
python3 aar_archiver.py <url> --pages 1-5 --epub
```

## Если форум не отдаёт страницы

Форум Paradox закрыт Cloudflare и иногда требует вход. Признаки: в `raw/`
лежит короткая страница-заглушка, либо постов нашлось 0.

Что делать по порядку:

1. **`--source wayback`** — скрипт спросит у web.archive.org, какие снимки
   страницы есть (CDX API), возьмёт самый свежий и распарсит его. Так
   получается копия даже без доступа к форуму, но только за те даты,
   которые архив успел снять, и без части картинок.
2. **Куки из браузера.** Откройте форум, войдите, скопируйте куки
   (расширение «Get cookies.txt» или DevTools → Network → Request Headers →
   `Cookie`) и передайте: `--cookies 'xf_user=…; xf_session=…'`.
3. **`--delay 5`** и обычный браузерный `--ua`, если запросы блокируют
   как автоматические.

Скрипт и сам пробует wayback как запасной вариант для страницы, которая
не скачалась с форума (в режиме `--source forum`).

## Тесты

Тесты работают без сети: HTTP-слой подменяется локальными фикстурами,
которые повторяют разметку XenForo 2 (ленивые картинки, спойлеры, цитаты,
подписи, пагинация).

```bash
python3 tests/test_archiver.py           # 25 проверок
python3 tests/test_archiver.py --demo    # собрать демо-копию в demo_out/
```

Проверяются: определение числа страниц (и что ссылки из сайдбара не
подхватываются), вырезание подписи, извлечение тела поста, дерево HTML
с незакрытыми `<p>`/`<li>`, Markdown (заголовки по `font-size`, списки,
таблицы, спойлеры, цитаты), локализация картинок из `data-src`,
структура EPUB (mimetype без сжатия, валидный XML, манифест) и весь
пайплайн целиком.

---

## Оговорка

Скрипт предназначен для **личной резервной копии** публично доступного треда,
чтобы читать его офлайн. Права на текст и скриншоты принадлежат автору AAR
и владельцам изображений: не выкладывайте и не распространяйте копию
без разрешения автора. Не используйте скрипт для массовой загрузки форума —
держите `--delay` и качайте только то, что читаете сами.
